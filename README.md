# Hojas & Momentos – Un viaje por el mundo del té

## Descripción del proyecto

Hojas & Momentos es un sitio web informativo dedicado al mundo del té. Su objetivo es ofrecer un recorrido por su historia, variedades, culturas, países productores, mezclas y formas de preparación, acercando al visitante a las tradiciones y experiencias que rodean esta bebida.

## Tecnologías utilizadas

- HTML5: estructura y contenido del sitio.
- CSS3: diseño visual, estilos y adaptación a diferentes dispositivos.
- JavaScript: funcionalidades e interactividad.

## Estructura del proyecto

- `index.html`: contiene la estructura y el contenido de la página.
- `estilos.css`: contiene los estilos visuales y el diseño.
- `script.js`: contiene las funciones e interacciones.
- `imagenes/`: almacena las fotografías y recursos gráficos utilizados.

## Secciones del sitio

1. Introducción
2. Historia del té
3. Variedades
4. Culturas y tradiciones
5. Países productores
6. Blends
7. Preparación
8. Bienestar
9. Galería
10. Contacto

## Funcionalidades

- Navegación entre las diferentes secciones.
- Buscador para filtrar contenidos.
- Almacenamiento local de la última búsqueda mediante `localStorage`.
- Formulario de contacto con validación de datos y mensaje de confirmación.
- Galería de imágenes.
- Visualización de la fecha de actualización.
- Botón para volver al inicio de la página.

**Nota:** el formulario tiene fines demostrativos. Valida los datos ingresados y muestra una confirmación en pantalla, pero no realiza el envío de correos electrónicos.

## Cómo visualizar el sitio

Para acceder al sitio, abrir el archivo `index.html` con un navegador web, como Google Chrome o Microsoft Edge.
